# Instalar el APK

1. Descarga `DealHunterAI-debug.apk` desde `releases/` o desde *Releases* en GitHub.
2. En el teléfono, permite instalar apps de esta fuente (Ajustes → Seguridad → Instalar apps desconocidas).
3. Abre la app, escribe la dirección de tu servidor y crea una cuenta (o «Continuar sin cuenta»).
4. En la app de cualquier tienda: **Compartir → Añadir a DealHunter**. Funciona con DealHunter cerrada.
